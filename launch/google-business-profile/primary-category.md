# Google Business Profile — Primary Category

## Primary Category (set this FIRST in GBP)

**Surgeon**

> This is the most appropriate top-level primary category. GBP categories map to Google Maps search intent. "Surgeon" is the highest-relevance category for a consultant with specialised surgical practice.

### How to set it
1. Go to business.google.com → Your Business → Edit Profile → Business category
2. Type "Surgeon" in the search box
3. Select **Surgeon** from the dropdown
4. Save

---

### Alternative Primary (if "Surgeon" has low visibility in Khammam local results)

**General Surgeon**

Try searching Google Maps for "general surgeon Khammam" — whichever GBP category dominates those results should be selected as primary.
